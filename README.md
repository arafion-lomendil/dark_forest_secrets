## О проекте

**Контекст.** «Секреты Темнолесья» — онлайн-игра, в которой игроки выбирают расу, класс персонажа и легендарную способность. От выбранной расы зависят особенности взаимодействия персонажа с игровым миром, а класс и легендарная способность определяют дополнительные возможности персонажа.

В игре используются две внутриигровые валюты. Обычные монеты позволяют покупать обычные предметы, а «райские лепестки» — эпические предметы, которые дают преимущество при прохождении игры. «Райские лепестки» можно получить за прохождение сложных квестов или купить за реальные деньги.

Продажа «райских лепестков» является основной частью дохода команды разработки. Команда планирует привлекать платящих игроков и продвигать покупку эпических предметов с помощью рекламы.

**Цель.** Изучить влияние характеристик игроков и их игровых персонажей на покупку внутриигровой валюты «райские лепестки», а также оценить активность игроков при совершении внутриигровых покупок.

**Задачи проекта:**

1. Рассчитать долю платящих игроков и изучить её в разрезе рас персонажей.
2. Исследовать основные характеристики внутриигровых покупок.
3. Выявить покупки с нулевой стоимостью и аномальные покупки.
4. Определить наиболее популярные эпические предметы.
5. Исследовать зависимость активности игроков по покупке эпических предметов от расы персонажа.
6. Сформулировать выводы и рекомендации для маркетингового отдела.

## Данные

Для анализа используется база данных онлайн-игры «Секреты Темнолесья».

В SQL-запросах используются следующие таблицы схемы `fantasy`:

| Таблица  | Что содержит                                                                              |
| -------- | ----------------------------------------------------------------------------------------- |
| `users`  | Данные об игроках, включая идентификатор, признак платящего пользователя и расу персонажа |
| `race`   | Данные о расах персонажей                                                                 |
| `events` | Данные о внутриигровых покупках и их стоимости                                            |
| `items`  | Данные об игровых предметах                                                               |

Для анализа используются поля, связанные с игроками, расами, покупками и предметами: `id`, `race_id`, `payer`, `amount`, `item_code`, `transaction_id`, `game_items`.

## Таблицы `users` и `race` используются для анализа платящих игроков в разрезе рас. Таблицы `events` и `items` используются для анализа внутриигровых покупок и популярных эпических предметов.

## Этапы работы

### 1. Исследовательский анализ данных

#### Доля платящих игроков

Рассчитана доля игроков, которые покупают внутриигровую валюту за реальные деньги:

* общее количество зарегистрированных игроков;
* количество платящих игроков;
* доля платящих игроков от общего количества пользователей;
* те же показатели в разрезе расы персонажа.

#### Исследование внутриигровых покупок

Рассчитаны основные статистические показатели поля `amount`:

* количество покупок;
* общая стоимость покупок;
* минимальная и максимальная стоимость;
* среднее значение;
* медиана;
* стандартное отклонение.

Отдельно исследованы покупки с нулевой стоимостью и их доля от общего количества покупок. Такие покупки исключаются при дальнейшем анализе.

После этого изучена популярность эпических предметов:

* количество продаж каждого предмета;
* доля продаж от общего числа покупок;
* количество игроков, купивших предмет;
* доля игроков, купивших предмет.

### 2. Решение ad hoc-задачи

Исследована зависимость активности игроков по покупке эпических предметов от расы персонажа.

Для каждой расы рассчитаны:

* общее количество зарегистрированных игроков;
* количество игроков, совершающих внутриигровые покупки;
* доля таких игроков от общего количества зарегистрированных;
* доля платящих игроков среди игроков, совершавших покупки;
* среднее количество покупок на одного игрока;
* средняя стоимость одной покупки;
* средняя суммарная стоимость покупок на одного игрока.

## Ключевые результаты

* **Платящие игроки.** Доля платящих пользователей составляет приблизительно **17,7 %** от общего числа пользователей. В зависимости от расы показатель изменяется незначительно; для Демонов доля платящих пользователей превышает 19 %.
* **Внутриигровые покупки.** За всё время игроками было совершено около **1,3 млн покупок** на сумму **686 млн райских лепестков**. Средняя покупка составляет 526 лепестков, медиана — менее 75, стандартное отклонение — 2518.
* **Аномальные покупки.** Аномальные покупки составляют менее **0,001 %** всех транзакций. Всего выявлено **907** таких покупок — все они относятся к предмету «Книга Легенд» (`Book of Legends`). 89 % этих приобретений сделаны одним пользователем.
* **Популярные эпические предметы.** Более 95 % купленных эпических предметов составляют «Книга Легенд» — около **77 %** покупок — и «Сумка для хранения» — около **20 %**. Доля игроков, покупавших эти предметы, также высока.
* **Активность по расам.** Для Северян и Эльфов средние разовые и суммарные траты на одного игрока выше, чем у остальных рас. Для Северян эти показатели составляют **762** и **62 520** лепестков, для Эльфов — **682** и **53 761**.
* **Общие выводы.** Доля игроков, покупающих игровую валюту за реальные деньги, находится примерно в диапазоне **16–20 %**. В материалах проекта отдельно отмечены расы Ангелов и Демонов: они являются наименее популярными, при этом для Демонов доля платящих игроков является наиболее высокой.
